The primary maintainer is responsible for project direction, review, releases, documentation, and decisions about contributions. This describes present stewardship; it is not a claim that every dependency, asset, or historical contribution was authored by one person.

## Project identity

**Chiboshi — Measurement Playground** is the English project name. **尺博士** is its original Chinese name. English documentation and a local development workflow make the project accessible to educators and developers.

The repository is maintained independently. No school, employer, platform provider, or funding program is represented as endorsing the project.

## Attribution

The project has used AI-assisted development and generated visual assets. Contributors remain responsible for checking correctness, explaining their changes, and identifying material AI assistance in pull requests. Preserve existing notices and record the origin and license of third-party material in `THIRD_PARTY_NOTICES.md` where applicable.

## Decisions and participation

Use repository issues for reproducible bugs, learning-content corrections, and proposals. Pull requests should explain the user-visible result and how it was checked. The maintainer makes merge and release decisions. Maintainer access is not granted automatically through a contribution.

For sensitive reports, follow [Security](SECURITY.md). There is no guaranteed response time or release schedule.
