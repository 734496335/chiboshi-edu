# 尺博士 — Measurement Playground

[English](README.md) · [入门指南](docs/GETTING_STARTED.md) · [学习指南](docs/LEARNING_GUIDE.md)

尺博士（Chiboshi）是通过视觉比较探索日常测量的教育项目，覆盖长度、质量、容积、面积、体积、时间六个维度。它用熟悉的物体连接数值与单位，引导学习者估计、比较、解释，再结合实际测量修正判断。

项目由 [@734496335](https://github.com/734496335) 独立维护。项目文档和主要入口使用英文；活动界面、参考数据和模型提示词仍有大量中文，完整英文体验尚待完善。

## 当前内容

- 量感沙盒：探索数量与尺度的关系。
- 参考字典：查看内置日常物体与测量示例。
- 创作工坊：配置独立的图像生成后端后，尝试实验性的 AI 辅助创作。
- 开发示例：学习单位转换、视觉比较、React 交互与服务端模型调用。

本项目没有持续维护的在线演示，请在本地运行。基础页面和参考字典可在不配置 API Key 的情况下探索；AI 相关操作需要可用的模型服务。部分资源也可能需要网络，暂不承诺完全离线使用。

## 本地启动

推荐 Node.js 22。在项目目录运行：

```bash
npm ci
npm run dev
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。需要 AI 功能时，将 `.env.local.example` 复制为 `.env.local`，填写 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。具体配置和验证方法见[入门指南](docs/GETTING_STARTED.md)。不要提交密钥或本地模型配置。

## 使用与贡献

学习活动适合由成人指导探索。参考值与模型输出需要结合实际物体或可靠资料核对；项目不声称已经证明教学效果，也不是经过校准的测量工具。请勿在模型输入中填写学生个人信息。
