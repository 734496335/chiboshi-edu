# Walkthrough transcript and teaching notes

**Chiboshi — Measurement Playground**  
Recorded from the real local application on 24 October 2026. English annotations accompany the existing Chinese activity interface. There is no audio; the written walkthrough and downloadable captions carry the explanation.

## 00:00–00:05 · Choose a learning activity

**On screen:** The English entry page, with Measure & Compare, Reference Library, and Creation Studio. The pointer selects Reference Library.

**Explanation:** Chiboshi connects numbers and units with familiar objects. Start with a question rather than a formula.

## 00:05–00:16 · Find a familiar reference

**On screen:** The length dictionary. The millimetre section includes sesame, rice, and an ant; the pointer then moves to the ten-centimetre section.

**Explanation:** This particular dictionary example puts an ant at about **5 mm**. It is an illustrative reference, not a claim that all ants have the same length. Use a real object or a trusted source when checking an estimate.

**Discussion prompt:** What nearby object could help you picture a few millimetres?

## 00:16–00:32 · Question an estimate, then revise it

**On screen:** The actual preset “蚂蚁长 5 米” means “an ant is 5 metres long.” The application compares that deliberately implausible input with its built-in car and school-bus references. The input changes to “蚂蚁长 5 毫米,” or “an ant is 5 millimetres long,” and the displayed references change to a sesame seed and a thumb-width example.

**Explanation:** **5 m = 5,000 mm.** A length of 5 mm is one thousandth of that length. The same numeral can describe a very different quantity when the unit changes.

**Discussion prompts:**

- Would a five-metre ant make sense next to a car?
- What changed when metres became millimetres?
- How would you check the revised estimate?

The recording uses the application's real deterministic fallback, with no provider credentials. It does not demonstrate an AI model verifying the answer. The fallback's prompt invites discussion rather than declaring an unverified measurement correct.

## 00:32–00:40 · Explore another quantity

**On screen:** The capacity dictionary's litre section shows a water-bottle example at about **550 mL**, a milk-carton example at **1 L**, and a kettle example at about **1.5 L**.

**Explanation:** Carry the same comparison habit into another measurement dimension. These are representative containers, not universal capacities for every bottle, carton, or kettle.

**Discussion prompt:** Find a labelled container. How does its stated capacity compare with one litre?

## 00:40–00:47 · Run, inspect, and contribute

**On screen:** A closing card with the repository address and the commands:

```bash
npm ci
npm run dev
```

**Explanation:** Run the project locally, inspect the source, and help improve examples, explanations, translations, accessibility, and regression checks.

## Recording boundaries

The pointer highlight and English frames were added for clarity. The underlying interface, input changes, API responses, and comparison results were captured from the application. No response was mocked or replaced. Waits and navigation were edited into short chapters; the film is not a latency benchmark.

The teaching notes describe an exploration sequence. They do not establish learning outcomes, curriculum certification, classroom adoption, or comprehensive reference-data accuracy.
