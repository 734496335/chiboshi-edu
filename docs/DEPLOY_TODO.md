# Hosted service retired

The previous hosted Chiboshi deployment was removed on 2026-10-24 at the maintainer's request. The project is now maintained as a local educational application and source repository.

Use [Getting started](GETTING_STARTED.md) for local development or [the classroom bundle guide](../classroom/README-classroom.md) for a local Windows presentation build. There is no maintained public demo endpoint.

Legacy cloud-deployment scripts and infrastructure details are intentionally excluded from the clean source distribution. Do not restore a cloud service as part of ordinary documentation or maintenance work.
