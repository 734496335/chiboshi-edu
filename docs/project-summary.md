# Chiboshi — Measurement Playground

Chiboshi is an independently maintained educational application for exploring everyday measurements through visual comparison. Its original Chinese name is 尺博士, and its owl guide is introduced in English as Dr. Measure.

The software contains a measurement sandbox, a reference dictionary, an experimental creation studio, and routes for length, mass, liquid capacity, area, occupied volume, and time. The repository's primary language is English; the current classroom activities and much of the reference data remain Simplified Chinese.

The primary maintainer is [@734496335](https://github.com/734496335), responsible for source maintenance, documentation, issue review, and release preparation. This identifies a current maintenance role and does not replace third-party attribution or assert independently validated learning outcomes.
